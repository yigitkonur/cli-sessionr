Usage: sessionr send [options] [session-id]

Send a message to an AI session (sync by default, --async for background)

Arguments:
  session-id             Session ID to resume (omit with --new)

Options:
  -m, --message <text>   Message to send (inline)
  -f, --file <path>      Read message from file (e.g. prompt.md)
  -s, --source <source>  Tool source — required with --new (claude, codex,
                         gemini, copilot, cursor-agent, commandcode, goose,
                         opencode, kiro, zed)
  --new                  Create a new session instead of resuming
  --async                Run in background and return job ID
  --cwd <dir>            Working directory (default: current)
  --tokens <n>           Token budget for response
  -p, --preset <name>    Verbosity preset (minimal, standard, verbose, full)
                         (default: "standard")
  -h, --help             display help for command
